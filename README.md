# NYC AI Map 🗺️

An interactive, force-directed network visualization of the people, organizations, startups, and companies shaping the AI landscape in New York City.

## Features

- **Network graph** — 55+ entities connected by professional and institutional relationships
- **Filter by type** — People, Orgs, Startups, or Companies
- **12 categories** — Frontier Lab, Academic, VC/Funder, Ethics/Civil Society, Government, and more
- **Search** — find any entity by name, description, or category
- **Hover tooltips** — click any node for details
- **Zoom & pan** — scroll to zoom, drag to pan, drag nodes to rearrange

## Entities include

People like Yann LeCun, Gary Marcus, Julia Stoyanovich, Matt Turck, Amy Webb, Joy Buolamwini, and Kate Crawford — organizations like AI Now Institute, NYU Center for Responsible AI, and Cornell Tech — startups like Hugging Face, Runway ML, and Dataiku — and companies like Google NYC, Meta AI, Bloomberg LP, and JPMorgan AI Research.

## Usage

No installation needed. Just open `index.html` in any modern browser.

## Stack

Built with [D3.js v7](https://d3js.org/) — fully self-contained, single HTML file, no backend required.

## Contributing

Data is compiled from public sources as of 2025. To suggest additions or corrections, open an issue or submit a pull request editing the `nodes` and `links` arrays in `index.html`.
